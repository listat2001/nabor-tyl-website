# Служба по контракту — сайт с формой заявок

Адаптивный многостраничный сайт с обработкой заявок на PHP и отправкой уведомлений через SMTP.

## Возможности

- Главная страница, страницы вакансий, контактов и политики обработки данных.
- Форма заявки с серверной валидацией и базовой защитой от спама.
- Отправка уведомлений через PHPMailer и SMTP.
- Адаптивная верстка и графические материалы.

## Стек

HTML5 · CSS3 · JavaScript · PHP · PHPMailer · SMTP

## Запуск

Статические страницы можно открыть локально. Для работы формы нужен сервер с PHP и SMTP-учётной записью.

1. Разместите файлы в корне веб-сервера с PHP.
2. Создайте файл `mail_config.php` **в родительском каталоге за пределами публичного корня сайта** по образцу `mail_config.example.php` (см. комментарий в образце).
3. Настройте SMTP-учётную запись и адреса отправителя/получателя в `send.php` для своего проекта.
4. Убедитесь, что конфигурационный файл не доступен по HTTP, включите HTTPS и протестируйте отправку.

**Без конфигурационного файла форма не отправляет письма.** Не добавляйте пароли, журналы ошибок и реальные заявки в Git.

## Структура

- `index.html` — главная страница
- `apply/` — форма заявки
- `vacancies/` — каталог и страницы вакансий
- `contacts/`, `privacy/` — дополнительные страницы
- `assets/` — изображения, иконки и JavaScript
- `style.css` — стили
- `send.php` — обработчик формы
- `phpmailer/` — библиотека отправки писем
